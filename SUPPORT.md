# Support

Use the route that matches the request:

- Bugs: open a bug report issue with reproduction steps and command output.
- Feature requests: open a feature request issue with the workflow problem and desired outcome.
- Usage questions: open a GitHub issue and include the skill version or commit.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), not public issues.

This is a small public utility repo, so support is best-effort and handled through GitHub.

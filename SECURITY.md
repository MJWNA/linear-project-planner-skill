# Security Policy

## Supported Versions

The `main` branch is the supported version of this skill.

## Reporting A Vulnerability

Do not report security vulnerabilities in public issues.

Use GitHub private vulnerability reporting for this repository when available, or contact the repository owner through GitHub with:

- affected commit or version
- impact summary
- reproduction steps
- proof of concept, if safe to share
- suggested remediation, if known

Security reports are reviewed before public disclosure. Please give the maintainer a reasonable opportunity to investigate and remediate.

## Scope

This repository contains a Codex skill, shell wrapper, Markdown templates, tests, and GitHub workflow files. It should not contain secrets, customer data, production exports, credentials, API keys, or private Linear workspace data.
